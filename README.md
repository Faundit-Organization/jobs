## Application skills

- [Engineer-Agent Interview](skills/engineer-agent-interview/SKILL.md) — a skill your coding agent runs to produce an AI setup artifact that describes how you use AI agents.

### How to use it

Give your coding agent the [link to the skill](skills/engineer-agent-interview/SKILL.md) or the [raw URL](https://raw.githubusercontent.com/faundit-organization/jobs/master/skills/engineer-agent-interview/SKILL.md), or open it and copy-paste the content into your agent. It will interview you about your AI setup and produce a markdown file you can attach to your application.
